# Cómo citar

## Repositorio

Tiempos Sustentables. (2026). *Tiempos Sustentables Open Data* [Data set]. GitHub. https://github.com/Tiempos-Sustentables/tiempos-sustentables-open-data

## Publicaciones

Para citar una publicación, utiliza preferentemente su DOI y su página canónica en Tiempos Sustentables.

Ejemplo APA 7:

Blasco Valencia, J. P. (2026). *Guía Estratégica de Negocios y Finanzas Sostenibles para el Liderazgo Comercial Latinoamericano*. Tiempos Sustentables. https://doi.org/10.5281/zenodo.20443605

## Prioridad de fuentes

1. DOI oficial.
2. Página canónica en Tiempos Sustentables.
3. Registro del repositorio: Zenodo, OSF o ResearchGate.
4. Perfil ORCID.
5. Este repositorio de datos abiertos.
