# Diccionario de datos

## `author.json`

| Campo | Descripción |
|---|---|
| `name` | Nombre canónico de la persona. |
| `alternateName` | Variantes públicas del nombre. |
| `url` | Página de autor oficial. |
| `identifier` / `orcid` | Identificador ORCID. |
| `worksFor` | Organización de afiliación. |
| `knowsAbout` | Áreas de especialidad. |
| `sameAs` | Perfiles externos equivalentes. |

## `publications.json` y `publications.csv`

| Campo | Descripción |
|---|---|
| `title` | Título oficial de la publicación. |
| `type` | Tipo o tipos Schema.org aplicables. |
| `authors` | Autores y ORCID cuando está disponible. |
| `date_published` | Fecha editorial de publicación. |
| `date_modified` | Fecha de última actualización relevante. |
| `doi` | Identificador Digital Object Identifier. |
| `doi_url` | URL de resolución del DOI. |
| `repository` | Repositorio donde está depositada la obra. |
| `canonical_url` | Página oficial en Tiempos Sustentables. |
| `pdf_url` | PDF público, cuando existe. |
| `license` | Licencia declarada. |

## `resource-center.json` y `resource-center.csv`

| Campo | Descripción |
|---|---|
| `name` | Nombre del recurso. |
| `type` | Tipo Schema.org. |
| `url` | URL canónica o ancla oficial. |
| `description` | Descripción breve. |
| `keywords` | Temas o marcos asociados. |
| `spatial_coverage` | Cobertura geográfica. |
| `license` | Licencia declarada. |
